# Obiettivo: creare una versione di wordpress in Node.

# Carattertistiche tecniche
- Backend: react router con SSR per il front
- Backoffice: tutto sotto /admin. Il pannello non deve avere il SSR, il front si.
- Funzionalità: le medesime di Wordpress (qui la repo https://github.com/WordPress/WordPress)
- Backoffice: usa SHADCN come pacchetto grafico
- DB: mysql/mariadb/postgres, usiamo Drizzle ORM 
- API: esponi api complete REST, sia per recuperare i dati del front, sia per gestire il back (admin API)
